# Description

## GitHub repo description (paste directly into settings)

A merged-persona invention council for Claude. Six historical thinking styles, paired against each other's blind spots, that argue with your idea instead of agreeing with it.

## Longer pitch

Officina is a Claude skill that treats invention as an argument, not a cheerleading session. Drop in an idea and it gets pushed through six merged thinking styles at once: Leonardo da Vinci, Isaac Newton, Nikola Tesla, Buckminster Fuller, Benjamin Franklin, and Vagadesamaso, a build-first modern maker archetype invented specifically to avoid naming a real living person. Every lens is paired with the one lens built to catch its own particular blind spot.

Before any of that starts, a separate stage checks whether the stated goal is even the right one to be chasing. And if you come back with a revised version of something already reviewed, it compares the revision against the original verdict instead of starting cold or crediting you for effort alone.

The result is a workshop, not a hype machine. Ideas either survive contact with six deliberately incompatible perspectives, or they don't. Either way, you get told why.

## One-line version

Six minds. Zero agreement by default. That's the whole point.
